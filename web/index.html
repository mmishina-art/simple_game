ルール
  • 0〜9 の数字を重複なしで並べた答えを当てます（先頭が 0 のこともあります）。
  • 数字も場所も合っていればヒット、数字だけ合っていればブローです。
    例: 答えが 1234 で 1395 と入力すると、1 ヒット 1 ブロー
  • 回以内に全部ヒットにすれば勝ちです。

    ホーム画面に追加して使う

    インストールすると、ホーム画面から開けて、オフラインでも遊べます。

    iPhone / iPad
    1. Safari でこのページを開く
    2. 共有ボタン（□から↑が出ているマーク）をタップ
    3. 「ホーム画面に追加」を選ぶ
    4. 右上の「追加」をタップ
    Android
    1. Chrome でこのページを開く
    2. 右上のメニュー（⋮）をタップ
    3. 「アプリをインストール」または「ホーム画面に追加」を選ぶ
    4. 「インストール」をタップ
    パソコン（Chrome / Edge）
    1. アドレスバーの右端にあるインストールのマークをクリック
    2. 「インストール」を選ぶ
    新しいバージョンがあります（更新すると、今のゲームは最初からになります）
